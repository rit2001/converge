# Benchmarks

Accepted M2 k6 results retain their workload, bounded environment, versions, validation, and explicit
limitations in their timestamped result directories. They are not production-capacity or SLA claims.

M3 frontend browser timing has no accepted result. See
[M3 web performance methodology and closure](./m3-web-performance.md) and the two timestamped
`UNACCEPTED.md` records. The deterministic production-build bundle checker remains available through
`pnpm check:web-budgets`.

Future accepted reports must include the workload, bounded non-sensitive environment, versions, raw
validated evidence, reproducible commands, and honest limitations.
